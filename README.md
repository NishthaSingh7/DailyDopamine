# DailyDopamine

## Project name
DailyDopamine

## Purpose
An all-in-one productivity web app for daily focus, habits, and lightweight personal organization.

## Features
- Home dashboard layout with header and footer
- Client-side routing with React Router
- Fast Vite-powered development and production builds
- Responsive React UI for everyday productivity use

## Tech Stack used
- React 19
- React Router
- Vite
- JavaScript (ES modules)
- ESLint
